# Industrial Casting Defect Detection using Deep Learning 🏭🔍

A deep learning–based **computer vision system** developed to automatically detect **defective and non-defective casting products** from images using **Transfer Learning with Xception**.  
This project simulates a real-world **industrial quality inspection** use case.

---

## 🚀 Key Features

- 🏭 Automated defect detection for industrial casting products
- 🧠 Transfer Learning using pretrained Xception model
- 📸 Binary image classification (Defective vs Non-defective)
- 📊 Training and validation performance visualization
- 💾 Model persistence for deployment and reuse
- 👤 User-input image prediction support

---

## 🛠️ Tech Stack

- **Programming Language:** Python  
- **Deep Learning Framework:** TensorFlow / Keras  
- **Model Architecture:** Xception (Transfer Learning)  
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn  
- **Dataset Source:** Kaggle (Industrial Casting Dataset)
